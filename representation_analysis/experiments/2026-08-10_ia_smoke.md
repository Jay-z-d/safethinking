# IA representation-separability smoke test (2026-08-10)

## Status

Pipeline validation completed successfully. This run is a smoke test and is not evidence for a research conclusion.

## Setup

- Model: `Meta-Llama-3.1-8B-Instruct`
- Method: `safe_llm_intention_analysis`
- Dataset: 20 paired WildJailbreak examples (20 benign and 20 harmful queries)
- Seed: 42
- Representation: final transformer layer (`hidden_state_index=32`), last-token pooling
- Probe: logistic regression, 5-fold pair-grouped cross-validation, `C=1.0`
- Checkpoints: `h_query`, `h_guided`, and `h_reasoned`
- Extracted representations: 40 samples x 3 checkpoints = 120 vectors

Under the current fixed-OOF pair bootstrap, the 95% interval for the end-to-end AUC delta is `[-0.0725, 0.0226]`, and the interval for the balanced-accuracy delta is `[-0.125, 0.075]`. Both include zero. The end-to-end signed-margin interval is `[-5.467, -1.523]`, but this interval should not be treated as confirmatory because the current bootstrap does not retrain the probe.

## Preliminary interpretation

1. The original benign and harmful queries are already highly linearly separable.
2. Adding the IA guidance prompt substantially reduces separability at the last-token checkpoint.
3. Adding the generated intention analysis and the subsequent stage-2 prompt structure restores much of that loss.
4. The final `h_reasoned` representation does not exceed the original `h_query` representation in this run. The result therefore does not currently support the end-to-end "reasoning increases linear separability" hypothesis.
5. A plausible measurement explanation is that the shared guidance template makes the last-token states more similar, while the generated analysis reintroduces content correlated with harmfulness. This is a hypothesis to test, not a conclusion from the current data.

## Important limitations

- Only 20 pairs, one seed, one model, one method, one layer, and one pooling strategy were evaluated.
- `h_guided` and `h_reasoned` do not isolate a pure reasoning intervention. The transition also adds generated analysis, a fixed continuation prompt, chat turns, and assistant headers.
- The scaler is fitted jointly on the before/after training representations. Because the scaler changes between comparisons, absolute margins and even repeated checkpoint baselines should not be compared across separate result files.
- The reported signed margin is in standardized feature space, not the original hidden-state geometry.
- Out-of-fold scores from different fold models are pooled, and the bootstrap resamples fixed predictions without retraining. Its confidence intervals omit model-fitting and split uncertainty.
- Strong query-level separability may reflect lexical or topical cues in this small dataset rather than a general safety boundary.

## Next steps before a formal experiment

1. Add empty, shuffled, and length-matched analysis controls, or extract the hidden state exactly at the end of the generated analysis before the continuation prompt.
2. Fit a fixed transform using only the `h_query` training representation (or freeze one shared transform across methods), and report whether margins are standardized-space or raw-space quantities.
3. Enforce complete benign/harmful membership for every `(pair_id, run_id)` and matching checkpoint keys.
4. Replace the fixed-prediction bootstrap with repeated pair-grouped cross-validation or an outer pair bootstrap that retrains the probe; tune `C` in an inner grouped split.
5. After those fixes pass tests, increase the number of pairs and seeds, then add native-reasoning models and training-based safety methods.
